# Lasertag Verden

The website for **Lasertag Verden**, providing visitors with arena information, current offers, prices, opening hours, and an online reservation experience.

## Overview

Lasertag Verden is a laser tag arena using LaserForce Gen8 equipment. This project is the customer-facing website and reservation interface, designed for desktop and mobile visitors.

Alongside the main pages, the site includes a multi-step booking wizard. Visitors choose an offer, number of participants, and a suitable time slot before signing in or creating a customer account to submit their reservation.

## Features

- Responsive website with a dark, arena-inspired visual design
- Home page with live opening-status calculation for the Europe/Berlin timezone
- Information about the arena, equipment, prices, specials, gallery, contact details, and parent consent form
- News and promotion banners shared across relevant pages
- Online booking wizard with offer, participant, date, time, account, and confirmation steps
- Live service and availability data from SimplyBook
- Customer registration, login, password reset, and session-based booking flow
- Offer-specific participant limits and booking validation
- Short-lived caching for SimplyBook authentication, services, and availability requests
